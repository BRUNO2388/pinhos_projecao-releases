# Pinhos Projeção — instaladores

Canal oficial de distribuição do Pinhos Projeção para Windows.

Os instaladores serão disponibilizados em [Releases](https://github.com/BRUNO2388/pinhos_projecao-releases/releases).

Este repositório não contém o acervo de louvores ou dados da igreja.
Uma instalação nova começa vazia. Atualizações preservam o acervo já cadastrado.

A primeira versão com o menu de atualizações deve ser instalada manualmente.
Depois, use **Ajuda → Buscar atualizações** com conexão à internet.
Instale após o culto: a instalação encerra a projeção e o chat.

A primeira publicação está em preparação. Não use o ZIP automático de código-fonte como instalador.
